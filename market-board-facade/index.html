How this page is built. The source data lives in the private Drive repository under market-board-facade/. A pipeline there reads the spreadsheets, keeps only the nine canonical columns, sums them per month, and publishes just those aggregates to this public repository. Row-level data, identifiers, descriptions and contact details are never published, and a check in this repository blocks spreadsheets from being committed. The market database (uploads, automatic updates, or extraction from the Fin Lab) will replace the sample feed when it exists.

Tooltips and the Table toggle on each chart show the same numbers in text form.
