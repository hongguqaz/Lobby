Google Drive

이 기기에서 Google Drive에 로그인되어 있지 않습니다.

Google Cloud의 OAuth 클라이언트 ID가 설정(⚙)에 입력되어 있어야 합니다. 첫 연결에서 "Google Drive의 모든 파일 보기, 수정, 생성, 삭제" 권한을 승인하세요. 이 앱은 Drive에서 아무것도 삭제하지 않습니다.

GitHub

저장된 GitHub 토큰이 없습니다.

토큰 만들기: Fine-grained token 새로 만들기 → Repository access는 Only select repositories → Drive, Repository permissions는 Contents → Read and write. 이미 만든 토큰은 토큰 목록에서 열어 같은 두 항목을 고칠 수 있습니다(토큰 값은 그대로). Lobby README의 LOBBY_DEPLOY_TOKEN은 다른 용도(Lobby 저장소)의 토큰입니다.

          켜 두면 정해진 주기마다 기능 2(Flow Matching)를 자동으로 실행합니다. 선결 조건이 하나라도 빠지면 실행하지 않고 사유를 남깁니다.

      브라우저 앱은 이 페이지(또는 설치한 앱 창)가 열려 있는 동안만 자동 실행됩니다. 창을 닫거나 기기가 잠들면 멈추고, 다시 열면 밀린 실행을 바로 처리합니다. Google 로그인 토큰은 1시간마다 갱신되며, 갱신에 실패하면 실행을 멈추고 재로그인을 요청합니다. 하루 이상 무인 실행하려면 설정의 "장기 인증"을 켜 두세요.
      
          
      
        
      
      
      

      
      
      
        
          A
          Agent 인터페이스 window.DrivesSync
          에이전트(자동화 도구, Claude 등)가 이 앱을 조작할 때 쓰는 API와 상태. 같은 사전 점검(브레이크)이 그대로 적용됩니다.
          API
        
        
      
          
      
            
            
            
          
      
          
      
          
      
            API 요약

      await DrivesSync.preflight()                      // 사전 점검 → { ok, reasons[], checks[] }
await DrivesSync.runStock({ dryRun })             // 기능 1 → 결과 또는 { ok:false, braked:true, reasons[] }
await DrivesSync.runFlow({ folderIds, dryRun })   // 기능 2 (지속 접근 폴더만 무인 실행 가능)
await DrivesSync.automation.enable({ intervalMinutes })   // 기능 3 → 선결 조건 미충족 시 { ok:false, reasons[] }
DrivesSync.automation.disable() / .status()
DrivesSync.getState()                             // 설정(토큰 제외), 마지막 점검·실행 결과, 폴더, 자동화 상태
DrivesSync.config.get() / .set({ github: { targetPath } })
DrivesSync.folders.list() / .remove(id)
DrivesSync.tokens.setGitHub(token)                // Google 로그인은 사용자 동작이 필요 (또는 장기 인증)
DrivesSync.logs.get(200)
document.body.dataset.state                       // idle | running | braked | error
