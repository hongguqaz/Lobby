연결 설정

이 게시판은 비공개 저장소의 보고서 폴더를 GitHub API 로 직접 읽습니다. 토큰은 이 브라우저(localStorage)에만 저장되고 api.github.com 외에는 어디에도 보내지 않습니다. 토큰은 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained: Repository access 에 Drive, Permissions 에 Contents: Read-only 로 만듭니다. 두 게시판(FixC report · FixC Daily Picks)이 같은 설정을 씁니다.
